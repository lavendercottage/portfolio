# Simple Markdown guide

| What you want to do | Markdown                       |
| ------------------- | ------------------------------ |
| Heading             | `# Heading`                    |
| Subheading          | `## Subheading`                |
| Bold text           | `**bold**`                     |
| Italic text         | `*italic*`                     |
| Bulleted list       | `- Item`                       |
| Numbered list       | `1. Item`                      |
| Link                | `[GitHub](https://github.com)` |
| Image               | `![Description](image.png)`    |
| Inline code         | `` `code` ``                   |
| Code block          | ` ``` `                        |
