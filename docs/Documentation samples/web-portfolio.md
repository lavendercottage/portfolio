# Web Portfolio

This section is ideal for showcasing web applications, landing pages, and product experiences. Each project can include a short summary, the problem it solved, tools used, and a link to the live experience.

## Example structure

- Project name
- Role and contribution
- Technologies used
- Outcome and impact

Use this page to present a curated set of your strongest interface and development work.
