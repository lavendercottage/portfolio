# Example: User Cannot Log In

## Issue

*Describe the problem from the user's perspective.*

Example:

Users receive an error message when trying to sign in to the application.

---

## Symptoms

The issue may include:

- Login page loads normally.
- User enters valid credentials.
- Error message appears after submitting credentials.

<br />

Example error:

> Authentication failed. Please try again.

---

## Affected Systems

| Item | Description |
|------|-------------|
| System | Customer Portal |
| Environment | Production |
| Affected users | All users / Specific users |

<br />

# Troubleshooting Steps

## Step 1 – Verify the issue

Check that:

- The user can access the login page.
- The issue can be reproduced.
- Other users are affected or not.

**Expected result:**

The issue is confirmed.

---

## Step 2 – Check user account status

Verify:

- Account is active.
- Password has not expired.
- User has required permissions.

**Resolution:**

Reactivate the account or update permissions if required.

---

## Step 3 – Check service status

Verify that required services are running.

Check:

- Application status
- Authentication service
- Network connectivity

**Expected result:**

All services report normal status.

---

## Step 4 – Clear local data

Ask the user to:

1. Close the browser.
2. Clear cached data.
3. Restart the browser.
4. Try again.

---

# Resolution

The issue is resolved when:

- User can successfully log in.
- No error message is displayed.

---

# Escalation

Contact support if:

- The issue affects multiple users.
- Authentication services are unavailable.
- Troubleshooting steps do not resolve the issue.

Provide:

- Username
- Timestamp
- Error message
- Screenshot
- Browser version
