# Documentation overview

This portfolio is a Docusaurus-based home for work, ideas, and digital storytelling. It is designed to grow as new case studies, projects, and experiences are added.

<br />

>**This site is best experienced using the navigation sidebar and search. If you're looking for a specific topic, searching is often the fastest way to find it.**

<br />


# How to use

Whether you're using a desktop computer, tablet, or mobile device, the navigation is designed to help you find information quickly.

## Desktop

On larger screens, you'll find the navigation menu in the left-hand sidebar. Use it to browse topics and move between related articles.

You can also use the search function at the top of the page to quickly locate specific content.

## Mobile

On smaller screens, the navigation menu is hidden to maximise reading space.

Tap the **menu icon (☰)** in the top-left corner to open the documentation sidebar. From there, you can browse sections, expand categories, and jump directly to another page.


## Navigating Within a Page

Many pages include a table of contents on the right-hand side (or at the top on smaller screens). Use it to jump directly to a specific section without scrolling through the entire document.

Internal links throughout the documentation connect related topics and provide additional background where needed.

## Documentation Structure

The documentation follows a task-based structure. Each section focuses on a specific topic or workflow, allowing you to read only what you need.

If you're new to the site, it's recommended to start with the **Getting Started** section before exploring more advanced topics.
